# Linux VM Lab Guide

This guide complements the interactive knowledge check and the module notes. It takes you through connecting to a real Ubuntu VM using SSH, practicing Linux administration, verifying results, and submitting evidence.

[Start the guided Linux VM lab](task-1-linux-practice.html)

The lab supports local VirtualBox, WSL2, or a cloud Ubuntu VM. For cloud practice, keep SSH restricted to your own IP address, protect your private key, watch for charges, and delete resources when finished.
