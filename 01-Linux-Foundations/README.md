# Module 01: Linux and Git Foundations (Weeks 1–2)

## Materials

- [Linux Fundamentals notes](notes.md)
- [Task 1: Linux Fundamentals Practice](task-1-linux-practice.md)

## Topics

Linux filesystem, permissions, processes and systemd, package managers, SSH and keys, networking basics (IP, CIDR, DNS, HTTP/HTTPS, ports), Git branching and pull requests, Bash basics, Python for automation.

## Labs

1. Complete [Task 1](task-1-linux-practice.md).
2. Host a static site with Nginx on your Linux machine or VM.
3. Write a Bash script that checks disk usage and prints a warning above 80%.
4. Open a pull request with your solution and review one peer's pull request.

## Deliverable

A `foundations` folder or repo with your scripts and a README explaining each.
