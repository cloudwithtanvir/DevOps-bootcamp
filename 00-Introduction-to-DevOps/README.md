# Module 00: Introduction to DevOps and Onboarding (Week 0)

## Materials

- [Introduction to DevOps notes](notes.md): what DevOps is, its history, core principles and culture.

## Week 0 onboarding checklist

- [ ] Join the group channel and read the group rules
- [ ] Create a GitHub account (if needed) and fork this repository ([HOW-TO-SUBMIT.md](../HOW-TO-SUBMIT.md))
- [ ] Create a public repo called `devops-journey` with a README introducing yourself and your goal
- [ ] Install the tools: VS Code, Git, a Linux terminal (Ubuntu, or WSL on Windows), Docker Desktop or Docker Engine
- [ ] Create an AWS free-tier account and set a **billing alarm at $5** before doing anything else
- [ ] Fill in the self-assessment form (rate yourself 1–5 on Linux, networking, Git, cloud, scripting)
- [ ] Post your one-sentence goal in the group channel

## Pre-task (48 hours)

Push your `devops-journey` README and share the link in the group. This is the first proof that you can follow through.
