# 12-Week Roadmap

Six phases after a Week 0 onboarding. Every module reuses the same sample app, so by Week 12 it has grown into your capstone: app → Docker → Kubernetes → CI/CD → Terraform → monitoring.

| Weeks | Module | Key topics | Hands-on lab / deliverable | Career track |
| --- | --- | --- | --- | --- |
| 0 | [00 Onboarding](00-Introduction-to-DevOps/) | What DevOps is, tools setup, billing alarms | GitHub repo with a personal README | Set a one-sentence goal |
| 1–2 | [01 Linux and Git](01-Linux-Foundations/) | Linux, permissions, processes, SSH, DNS/HTTP, Git, Bash, Python basics | Linux practice task; Nginx site; disk-alert script | Pick a target role |
| 3–4 | [02 Cloud](02-Cloud-Fundamentals/) | VMs, IAM, EC2, S3, VPC, RDS, Lambda, cost control; Azure and GCP mapping | VPC with public/private subnets + load balancer; AWS vs Azure vs GCP service map | Learn in public (LinkedIn posts) |
| 5 | [03 Docker](03-Docker/) | Images, layers, multi-stage builds, Compose, registries | Dockerize the sample app | Resume draft |
| 6–7 | [04 Kubernetes](04-Kubernetes/) | Pods, Deployments, Services, Ingress, probes, Helm | Sample app on kind, packaged as a Helm chart | LinkedIn + networking |
| 8 | [05 CI/CD](05-CI-CD/) | GitHub Actions, image scanning, GitOps with Argo CD, Ansible | Push-to-deploy pipeline | |
| 9 | [06 Terraform](06-Terraform-IaC/) | Providers, state, modules, plan/apply in CI | Week 3–4 infrastructure rebuilt in Terraform | Certification plan + 20 target companies |
| 10 | [07 SRE](07-SRE-and-Monitoring/) | SLIs/SLOs, Prometheus, Grafana, alerting, incidents | Dashboard, SLO alert, postmortem | |
| 11 | [08 AI](08-AI-in-Cloud-and-DevOps/) | AI assistants for DevOps, cloud AI services, MLOps basics | Containerized AI app with its own pipeline | Mock interviews |
| 12 | [09 Capstone](09-Capstone/) | End-to-end system | 15-minute demo, scored on a 100-point rubric | Applications + referrals |

## Weekly rhythm

- **Session 1 (weekday evening):** concept, live demo, lab kick-off.
- **Session 2 (weekend):** lab review, troubleshooting, career slot (every other week).
- **Async:** daily "Today I learned / blocked on" posts in the group channel.
- **Friday:** one participant gives a 5-minute "what I built" demo.

## 90-minute session template (for mentors)

1. Check-in and wins from last week (10 min)
2. Concept with a diagram (20 min)
3. Live demo, ideally including a mistake fixed on screen (20 min)
4. Guided hands-on (30 min)
5. Q&A, homework and a one-line recap from each person (10 min)
