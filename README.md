# DevOps, Cloud & AI Bootcamp

A free, hands-on, 12-week program by **Tanvir Ahmed** that takes participants from IT basics to a job-ready Cloud/DevOps portfolio, with career guidance throughout. Built for a small batch of Bangladeshis living abroad who want to build a career in Cloud, DevOps, SRE or platform engineering.

**Learn by building:** every topic is followed the same week by a lab that you build, break, fix and explain back to the group.

## Start here

1. Read the [12-week roadmap](ROADMAP.md).
2. Complete the [Week 0 onboarding checklist](00-Introduction-to-DevOps/README.md#week-0-onboarding-checklist).
3. Learn the [submission workflow](HOW-TO-SUBMIT.md): every task is submitted as a pull request, just like real engineering work.

## How the program runs

- **Two live sessions per week** (90 minutes each), recorded for different time zones, plus 4–6 hours of self-paced labs.
- **Discussion in Bangla**, technical terms and documentation in English.
- **Cost:** free. Labs run locally (Docker, kind, Terraform) or on cloud free tiers. Always set a billing alarm and destroy cloud resources after each lab.
- **One condition:** when you land an IT job through this journey, you owe your mentor a dinner.
