# Module 08: AI in Cloud and DevOps (Week 11)

*Status: coming soon. Topics and labs below are the plan.*

AI is a productivity multiplier for engineers who understand the fundamentals, not a replacement for them. This module teaches you to use it and to check it.

## Topics

Using AI assistants for scripting, debugging, writing Terraform and reviewing pipelines (and verifying their output); cloud AI services (Amazon Bedrock and SageMaker, Azure OpenAI and Azure ML, Google Vertex AI); MLOps basics (packaging, serving and monitoring models); AIOps ideas such as anomaly detection and log summarization; security and cost concerns for AI workloads.

## Labs

1. Use an AI assistant to generate a Terraform module, then review it, find the mistakes and fix them.
2. Deploy a small AI-powered API (for example, a log summarizer) in a container with its own CI/CD pipeline.
3. Add an AI step to a pipeline, such as summarizing failed test logs.

## Deliverable

A containerized AI app deployed through your pipeline, plus a short note on what the AI got right and wrong.
